# CSV 다듬

공개 도구: https://csv-dadeum.netlify.app/

한국어 CSV 검사·정리 도구. 입력은 기기에서만 처리합니다.

- 쉼표/탭/세미콜론/파이프, 큰따옴표 이스케이프, 셀 내부 줄바꿈 파싱
- 불균일한 열 수, 빈 행, 중복 데이터 행, 중복·빈 제목 검사
- 선택적 공백/중복/빈 행 정리, 원문 보존
- 전체 CSV 및 행 배열 JSON 저장, 기본 수식 실행 방지 옵션
- UTF-8 엄격 디코딩, 파일 5MiB·20,000행·200열 제한
- 첫 20행/12열 미리보기, 외부 요청·광고·분석·런타임 의존성 없음

`npm test`로 파싱과 데이터 보존, 정리, 수식 이스케이프를 검사합니다. 정적 서버에서 `dist/`를 제공합니다. 열 수가 다른 행의 값은 자동으로 삭제·패딩하지 않습니다. JSON은 제목 충돌에 따른 데이터 유실을 막기 위해 객체 대신 배열을 사용합니다. 수식 실행 방지를 켜면 음수를 포함해 수식처럼 시작하는 값을 텍스트로 저장합니다.

Netlify에서 공개하며 canonical·robots.txt·sitemap.xml을 포함합니다. 광고·결제 연결은 아직 없습니다. 복제 배포할 때는 실제 주소와 본인의 검색 소유권 태그로 메타데이터를 변경하세요.
